# PUBG Match Tracker

## Опис проєкту
Програма для обліку та аналізу матчів у PUBG.

## Для кого
Для гравців PUBG, які хочуть відстежувати свою статистику.

## Дані матчу
- Дата матчу
- Результат
- Кількість вбивств
- Тривалість матчу
- Коментар

## Функціонал
- Додавання матчу
- Перегляд усіх матчів
- Пошук матчів
- Формування статистичного звіту

## Технології
Python, Git, GitHub.

## Запуск програми
python cli.py
